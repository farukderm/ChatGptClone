# ChatGptClone

Projemizde Html Css ve Js kullanarak ChatGpt klonunu oluşturduk api ile bağlantı kurup sorduğumuz soruları cevaplamasını sağladık

# Kullanılan Araçlar
- Html
- Css
- Js
- ChatGpt api (rapidapi)
